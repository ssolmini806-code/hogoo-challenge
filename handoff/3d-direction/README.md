무료 사이트(`hogoo-challenge.pages.dev`)에서 검증한 3D 히어로 접근법을
유료 사이트에서 재현·확장하기 위한 명세입니다.

---

## 1. 무엇을 썼나

**ThreeUI Community** (https://github.com/MengTo/threeui) — MIT, © 2026 Meng To.
50개 Community 컴포넌트가 MIT로 공개돼 있고, Pro 45개 + Beta 2개는 제외돼 있습니다.

검토한 것 중 실제로 쓴 것:

| 컴포넌트 | 정체 | 판단 |
|---|---|---|
| `sylva-living-world` (`living-green`) | 절차적 이끼·뿌리·고사리·꽃가루·나비 생태계 | **채택** — 브랜드명 Ecosystem과 맞물림 |
| `temple-night` (Kage) | 절차적 교토 산사, 16패스 블룸 | 보류 — 일본 신사 도리이가 한국 심리 사이트와 문화적으로 불일치 |
| `stream-convergence` | 2D 배경 셰이더 | 폐기 — 3D가 아니고 의미 없음 |
| `gallery` | 원통형 3D 이미지 갤러리 | 폐기 — 임팩트 부족 |

**주의**: `sakura-sunset`, `maple-autumn`은 **Pro 전용**이라 오픈소스 레포에 없습니다.
태그 메타데이터만 남아 있고 구현체는 유료 멤버십 + `npx @designcodeio/threeui-cli add`로만 받습니다.

## 2. 반드시 지켜야 할 라이선스 조건

MIT는 **저작권 고지와 라이선스 전문을 사본에 포함**할 것을 요구합니다.
유료 사이트에서도 동일하게 `THIRD_PARTY_LICENSES.md`를 두어야 합니다.
무료 사이트 쪽 파일을 그대로 참고하세요.

절대 쓰면 안 되는 것:
- `threeui.com`에서 로드되는 카탈로그 썸네일·프리뷰 영상 — **MIT 적용 대상이 아니며 재배포 금지**
- Pro / Beta 컴포넌트 소스

권고: 상업적 전면 사용 전에 원저작자(Meng To) 확인을 받아두는 것이 안전합니다.
렌더러 헤더에 `Canonical source: kage-github/index.html`처럼 제3자 원본이 표기된 경우가 있습니다.

## 3. "베꼈다" 소리를 피하는 방법 — 실제로 한 조정

MIT는 수정을 허용합니다. 원본 Sylva는 **올리브/황록** 세계인데,
GIVE 브랜드 그린(`--primary: #00a885`)에 맞춰 상수를 직접 바꿨습니다.
치환 목록은 `build.mjs`의 `BRAND` 배열에 전부 주석과 함께 있습니다.

| 대상 | 원본 | 우리 값 |
|---|---|---|
| 키 라이트 | `Color(1.14, 1.06, 0.88)` | `Color(0.88, 1.12, 1.02)` |
| 바닥 반사광 | `Color(0.78, 0.78, 0.62)` | `Color(0.54, 0.86, 0.79)` |
| 환경광 | `Color(0.086, 0.090, 0.080)` | `Color(0.058, 0.098, 0.092)` |
| 대기 헤이즈 | `Color(0.176, 0.195, 0.145)` | `Color(0.098, 0.196, 0.178)` |
| 월드 바탕 | `#4a4d44` | `#26332f` |
| 근경 잔디 | 190,000 (모바일 70,000) | 138,000 (모바일 52,000) |
| 원경 잔디 | 60,000 (모바일 20,000) | 44,000 (모바일 15,000) |
| 꽃가루 | 4,200 (좁은 화면 1,500) | 5,600 (좁은 화면 2,100) |

여기에 **레이아웃·타이포그래피·메뉴 구조·카피는 전량 자체 제작**입니다.
ThreeUI는 Instrument Serif / Lexend / Onest를 쓰고, 우리는 Hahmlet + Noto Sans KR입니다.

## 5. 로딩 진행률은 실측이어야 합니다

시간 기반으로 흉내 낸 `%`를 쓰지 마세요. 측정 없이 UI에 숫자를 띄우지 않는 것이 원칙입니다.

구현 방식: **THREE 생성자를 감싸 실제 객체 생성 횟수를 셉니다.**

```js
// loader.js 의 countThree()
['Mesh','InstancedMesh','Points','LineSegments','BufferGeometry',
 'ShaderMaterial','MeshStandardMaterial','MeshBasicMaterial']
```

보정치(실측):
- Kage temple-night: **328개**, 씬 구축 약 3.9초 (소프트웨어 GPU 기준)
- Sylva living-green: **54개**

iframe 안의 씬은 카운터가 `postMessage`로 부모에 진행 상황을 보냅니다.

## 6. 성능에서 반드시 피해야 할 함정

무료 사이트에서 실제로 겪은 사고입니다:

- **`requestIdleCallback`으로 3D 부팅을 감싸지 마세요.** GA·Clarity·AdSense·Userback이
  붙는 동안 유휴가 잡히지 않아 **라이브 실측 23.7초** 뒤에야 월드가 나타났습니다.
  그동안 화면은 이전 배경 그대로라 "아무것도 안 바뀐" 것으로 보입니다.
- 씬 구축 4.5초 + 청크 로드 + 메인스레드 경합이 원인이었습니다. 프레임 자체는 7~8ms로 저렴합니다.
- 모바일 DPR은 1.5로 캡, 화면 밖·탭 비활성 시 `requestAnimationFrame` 정지는 필수입니다.

## 7. 전 페이지 적용은 3단으로

라이브 WebGL을 전 페이지에 깔지 마세요. 특히 **테스트 문항 페이지는 완료율이 깎입니다.**

| 단계 | 대상 | 방식 |
|---|---|---|
| 몰입 | 히어로, 결과 시퀀스, 인증서 | 라이브 3D |
| 정적 | 문항, 프롤로그 | 같은 월드의 **정지 프레임 이미지** |
| 질감 | 칼럼, 마이페이지, 약관 | WebGL 없이 CSS만 (종이결·번짐) |
